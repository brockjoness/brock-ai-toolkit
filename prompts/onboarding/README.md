# Onboarding prompts

Prompts that move someone from form submission to first session.

| Prompt | What it does |
|---|---|
| [intake-form-crm-routing](./intake-form-crm-routing) | Watches Gmail for form submissions, enriches, scores, routes, and sends an auto-reply from the assigned owner's Gmail |
| [appointment-no-show-recovery](./appointment-no-show-recovery) | Runs a 3-touch email recovery sequence on no-shows over 72 hours |
