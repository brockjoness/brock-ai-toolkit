# Prompts

This folder is paste-into-Claude.ai prompts — no setup, no dev environment, no API keys. Open a chat at claude.ai, paste the PROMPT.md, follow it with your inputs, get the output. Many of them also work as scheduled Claude Projects when paired with Gmail / Notion connectors. If a prompt has a scheduled variant, it's included in the same file.

For Claude Code skills (the kind that need a `.claude/skills/` directory, a dev environment, and sometimes external CLIs like Vercel or Perplexity), see [`/skills`](../skills) instead. Same prompts in many cases, but wired up for the developer workflow.
