# Client Status Update Writer

## What it is
A prompt for agency owners and account leads that produces client-facing comms in five common formats: weekly status, monthly recap, incident/delay, quarterly business review, and re-engagement. Output sounds like a senior partner — not a junior AE reading from a template.

## What problem it solves
Most agencies lose 4-6 hours a week writing comms manually, or delegate it to someone whose updates get read once and ignored. This produces tight (weekly < 200 words), honest, specific updates that end with a real CTA instead of "let me know if you have questions."

## Where to use it
Claude.ai (paste-and-go) or Claude Code (pairs with a Notion agency OS so it pulls client context automatically).

## How to run it
1. Paste PROMPT.md.
2. Tell Claude: client name, what you do for them, update type, and your activity notes for the period.
3. Get a ready-to-send email. Iterate on tone or length if needed.

## Inputs and outputs
**In:** client name, update type, wins, issues, blockers, activity notes.
**Out:** subject + opener + bullets + wins + issues + next steps + one-sentence CTA.

## Known limitations
- Won't replace real account strategy. It writes; you decide what to put in it.
- No real data pull — you give it the numbers, it formats them.
