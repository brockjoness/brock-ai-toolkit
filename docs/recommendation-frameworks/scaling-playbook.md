# Scaling Playbook

## When to use
ROAS is above target AND CPA is below target. Performance is strong -- time to scale.

## Decision Framework

### Step 1: Confirm scalability signals
- [ ] ROAS >= target for 7+ consecutive days
- [ ] CPA below target consistently (not a single-day spike)
- [ ] Frequency still within healthy range (<3.0 prospecting, <6.0 retargeting)
- [ ] Spend sample is meaningful (>$500 on the winning campaign/ad set)

### Step 2: Scale method selection

| Method | When to Use | Risk Level |
|---|---|---|
| **Vertical scaling** (increase budget on winning ad set) | Single winning ad set, frequency <2.5 | Low |
| **Horizontal scaling** (duplicate winning ad set to new audiences) | Winning creative, audience may be saturating | Medium |
| **Creative scaling** (iterate on winning creative with new variants) | Winner identified, want to multiply output | Low |
| **Platform expansion** (launch winning angles on new platform) | Strong Meta performance, client has Google/TikTok budget | Medium |

### Step 3: Budget increase rules
- **Safe increase:** 20-30% budget increase per 3-day period
- **Aggressive increase:** 50% increase (only if ROAS is 2x+ target and frequency <2.0)
- **Never:** 100%+ increase in a single day (resets learning phase)
- **Monitor:** 48 hours after each increase -- if CPA rises >20%, pause the increase

### Step 4: Scaling checklist
1. Increase budget on top ad set by 20-30%
2. Duplicate winning ad set to 2-3 new audience segments
3. Create 3 new creative variants based on winning ad's angle/hook
4. Set frequency cap alert at 3.0 (prospecting)
5. Review performance 48 hours post-scale
6. If CPA holds: continue scaling. If CPA spikes: revert and investigate.

## Common Pitfalls
- Scaling too fast resets Meta's learning phase
- Duplicating ad sets without changing audiences creates auction overlap
- Ignoring frequency while scaling leads to fatigue-driven CPA spikes
- Not having fresh creative ready means scaling hits a ceiling fast
