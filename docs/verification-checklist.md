# Verification — Self-Check Before Delivery

Before delivering any client-facing output, verify compliance with the matched rules:

| Work Type | Self-Check |
|-----------|------------|
| **Email drafts** | Correct signature appended? Banned punctuation removed? Tone matches the account's voice profile? |
| **Proposals** | Correct agency "About" label? 2x2 grid layout? Content billing noted? Pricing matches tier? |
| **Notion writes** | Content under the correct CRM page (not standalone)? User explicitly asked for the write? |
| **Content (LinkedIn/X)** | Banned formatting removed? Arrow bullets (not dashes)? Matches voice DNA? No anti-pattern phrases? |
| **Meta audits (pre-access)** | Ad Library fetched? Creative patterns identified? Message match assessed? "What we'd do with access" included? No performance metrics claimed? |
| **Meta audits (post-access)** | Data quality passed? Baselines segmented? Top 3 winners/patterns/stops in exec summary? Landing page analysis included? Testing roadmap in action plan? |
| **Google audits (pre-access)** | Transparency Center fetched? Ad copy patterns identified? Landing page message match assessed? "What we'd do with access" included? No performance metrics claimed? |
| **Google audits (post-access)** | Data quality passed? Baselines segmented by campaign type? Search term analysis included? Top 3 winners/patterns/stops in exec summary? Landing page analysis included? Action plan with testing roadmap? |
| **Pre-onboarding** | All deliverables generated? Agency branding correct? Hub links work? All deploys succeeded? Call notes incorporated into roadmap? |
| **Client research** | Sources attributed? Thin data flagged? Verbatim quotes used? |

If any check fails, fix it before presenting the output. Do not mention the self-check process to the user unless asked.
