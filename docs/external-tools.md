# External tools I lean on

A few public repos I've forked, cloned, or studied while building the toolkit. None of these are mine — they belong to their authors and are listed here so you can find them too. I'm not redistributing any of them; this is a reading list.

## Skills and agent patterns

- **[anthropics/skills](https://github.com/anthropics/skills)** — Anthropic's official skill examples. Worth reading before you write your first SKILL.md.
- **[obra/superpowers](https://github.com/obra/superpowers)** — A larger collection of Claude Code skills covering everything from PDF handling to data analysis. Good for borrowing patterns.
- **[nickjwells/claude-skills](https://github.com/nickjwells/claude-skills)** — Practical skills with a community-built quality bar.

## Frontend / design

- **[anthropics/claude-code-frontend-design](https://github.com/anthropics/claude-code-frontend-design)** — Frontend design patterns paired with Claude Code.
- **[Impeccable](https://github.com/anthropics/impeccable)** — Style/quality scaffolding.

## Media tooling

- **[nanobanana-mcp-server](https://github.com/spences10/nanobanana-mcp-server)** — MCP server for Gemini's Nano Banana image generation, useful if you want to call image gen as a tool rather than a script.
- **[gogcli](https://github.com/steipete/gogcli)** — Useful CLI patterns; not directly used in this toolkit but worth a look.

## Job scraping

- **[py-linkedin-jobs-scraper](https://github.com/spinlud/py-linkedin-jobs-scraper)** — LinkedIn jobs scraper I've used for early-stage lead-list work.

## Personal knowledge / agents

- **[obsidian-agent-client](https://github.com/Pythagora-io/obsidian-agent-client)** — Client for integrating agentic workflows with Obsidian.

## Why these are listed and not vendored

When you fork or vendor a public tool, you take on the responsibility of keeping it current. For tools that aren't load-bearing in my workflow, I'd rather just point at the upstream repo. If you're building something similar, do the same — point, don't fork, unless you actually need to modify.
