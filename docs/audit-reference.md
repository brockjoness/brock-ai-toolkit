# Shared Audit Reference

## Messaging Angle Taxonomy

Group every active ad by its primary messaging angle:

| Angle Type | Description |
|---|---|
| Pain-point / problem-aware | Calls out a problem the customer has |
| Social proof / authority | Reviews, testimonials, "as seen in", UGC endorsements |
| Lifestyle / identity | Aspirational, "for people who...", persona-targeting |
| Feature-led / education | Product specs, how it works, ingredients, how-to |
| Promo / offer | Discounts, bundles, limited-time, urgency |
| Founder / brand story | Origin story, mission, behind-the-scenes |
| Comparison / switch | Us vs. them, "why we're different" |
| Emotional / milestone | Gifting, life events, memory-making, sentimental |

## Creative Quality Signals (No Performance Data Available)

- **Recency**: Newer ads are likely working (brands pause what fails). Ads running 30+ days suggest they're performing.
- **Variant count**: Multiple versions of the same angle/format suggest the brand is scaling it.
- **Production quality**: Professional vs. casual/UGC -- neither is better, but the mix matters.
- **Copy strength**: Specific, benefit-driven copy with clear hooks vs. generic product descriptions.
- **Format diversity**: Healthy accounts test multiple formats; single-format accounts have concentration risk.
- **Landing page alignment**: Strong match between ad promise and landing page delivery.

## General Audit Rules

- Never claim performance metrics you don't have
- Frame everything as "here is what we see and here is what we would change"
- If the Ad Library is inaccessible via fetch, use web search and note the limitation
