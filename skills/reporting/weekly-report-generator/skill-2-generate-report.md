# SKILL 2: Generate Report

## What to do

Using the analysis from Skill 1, generate the complete HTML weekly report.

### Step 1: Read base styles

Read the dark theme base styles:
```
./onboarding/pre-onboarding/templates/_base-styles.html
```

### Step 2: Load agency branding

Read the agency's `brand.md` and extract CSS variable values:
- `--accent` color
- `--font-heading`, `--font-body`, `--font-code`

### Step 3: Build HTML report

Generate a single `index.html` file using the base styles + agency branding. Structure:

**Hero Section:**
- Agency logo (top left) + Client logo (top right)
- Title: "Weekly Performance Report"
- Subtitle: "{Client Name} // {Date Range}"
- Date generated

**Section 1: Executive Summary**
- 3-sentence summary in a `.card.accent-border`

**Section 2: Spend vs. Budget**
- `.stats-grid` with stat cards: Total Spend, Budget, Pacing %
- If multi-platform: spend breakdown by platform

**Section 3: Key Metrics**
- `.data-table` with columns: Metric, This Week, Last Week, WoW Change, Target
- Use green/red color coding for WoW changes (green = improving, red = declining)
- Arrow indicators: up/down/flat

**Section 4: Top Performers**
- `.card` for each top ad
- Include: ad name, key metrics in `.stats-grid`, creative angle, recommendation

**Section 5: Bottom Performers**
- `.card` for each bottom ad
- Include: ad name, key metrics, diagnosis, recommendation

**Section 6: Trends**
- If 4+ weeks of data: metric trend summary
- Fatigue alerts in `.card.accent-border` if any flags triggered
- Budget pacing trend

**Section 7: Recommendations**
- `.angle-card` for each recommendation
- Include: What, Why, Expected Impact, Owner

**Section 8: Next Week's Plan**
- `.checklist` format: campaigns to scale, cut, launch, test

**Footer:**
- Agency branding
- "Generated by {Agency Name} // {Date}"
- Status indicator (green dot)

### Step 4: Generate OG image

Create `api/og.js` for social sharing:
- Background: agency-appropriate color
- Title: "Weekly Report // {Client Name}"
- Subtitle: "{Date Range}"
- Agency branding

### Step 5: Create package.json

```json
{
  "dependencies": {
    "@vercel/og": "^0.6.0"
  }
}
```

### Step 6: Write files to disk

Write to: `./reports/{client-slug}/week-{YYYY-MM-DD}/`
- `index.html`
- `api/og.js`
- `package.json`
