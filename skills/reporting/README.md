# Reporting Skills

Reports are how clients judge agencies between major milestones. These skills standardize the cadence (weekly, monthly), enforce that every recommendation cites supporting data, and produce shareable branded HTML links instead of slide decks nobody opens twice. Also includes mid-month pacing checks and a daypart engagement mapper.

## Skills

| Skill | What it does | Maturity |
|---|---|---|
| [budget-pacing-monitor](./budget-pacing-monitor/) | Mid-month pacing check: on-track / under / over with a recommended adjustment | working |
| [engagement-mapper](./engagement-mapper/) | Maps day-of-week × hour-of-day engagement to recommend posting/spend schedule | experimental |
| [monthly-report-generator](./monthly-report-generator/) | Full monthly client report with MoM trends, platform comparison, strategic narrative, next-month plan | production |
| [weekly-report-generator](./weekly-report-generator/) | Weekly performance report with WoW deltas, top/bottom performers, fatigue signals | production |

See each skill's `README.md` for setup, env vars, and limitations. The dashboard skill (sibling of these) is owned by a separate workstream and not included here.
