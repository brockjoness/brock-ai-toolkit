# SKILL 7: Action Plan

## When to use

After all prior skills have run. This is always the final analysis skill.

## What to do

### Subsection 1: Creative Testing Roadmap

Based on all findings from Skills 3-6, propose specific creative tests. This is the lighter-weight alternative to full briefs -- covering more ground with less detail.

**Video Concepts to Test** (3-5):
For each:
- Concept name (descriptive)
- Format (length, aspect ratio, style)
- Hook / opening line (actual copy)
- Structure (beat-by-beat, not full storyboard)
- Why test (cite specific data justification -- which gap, pattern, or opportunity does this address?)
- Recommended landing page
- Priority (1/2/3)

**Static Concepts to Test** (3-5):
For each:
- Concept name
- Visual direction (composition, style)
- Copy / headline (actual text)
- Why test
- Recommended landing page
- Priority (1/2/3)

**Copy Variations to Test** (2-3):
For each:
- Current approach vs. proposed test (specific headlines)
- Why test (what emotional/rational shift does this test?)

**Format Experiments** (1-2):
- Aspect ratio, video length, carousel structure, etc.
- Rationale

**Seasonal Angles** (if relevant):
- Upcoming seasonal opportunities tied to the calendar
- Specific concepts for each season

### Subsection 2: Full Creative Briefs (Top 1-3 Opportunities Only)

Generate full briefs ONLY for the highest-priority opportunities. The testing roadmap handles the rest at lighter weight.

For each brief:

**BRIEF #[N] -- [Opportunity Title]**

1. **Strategic Opportunity:** One paragraph. What did the data reveal? Reference specific metrics and compare to baseline. Why does this brief exist?

2. **Target Audience:** Who is this for? Age, gender, lifecycle stage, psychographic profile.

3. **Angle & Messaging Framework:** Core message, emotional/rational driver, objection to overcome.
   - Primary angle (recommended)
   - Alternative angle 1
   - Alternative angle 2

4. **Hook / Headline Options:** 3-5 specific hook options (actual copy lines). Label each with hook type (Pattern Interrupt, Problem-First, Social Proof, Curiosity Gap, Direct Benefit).

5. **Visual & Format Specs:**
   - Recommended format and dimensions
   - Visual direction (what the viewer sees in first 3 seconds)
   - Required elements (subtitles, hook overlay, product demo timing)
   - Do's (3 specific visual do's based on winning creatives)
   - Don'ts (3 specific visual don'ts based on losing creatives)

6. **KPI Targets:**

   | Metric | Account Baseline | Target for This Creative |
   |---|---|---|
   | Thumb-Stop Rate | X% | X% |
   | CPP | $X | $X |
   | ROAS | X.XX | X.XX |

7. **Test Parameters:**
   - Insert into: [campaign/ad set]
   - Test against: [control creative]
   - Minimum spend before decision: [$X]
   - Decision metric and threshold
   - If winner / if loser: next action

### Subsection 3: Prioritized Recommendations

3-5 bullets, High priority first.

Format: "We recommend [X] because [data showed Y]"

Include directional budget guidance:
- If a bucket or format has significantly better ROAS, recommend increasing its share
- If an ad or bucket is burning spend with poor returns, recommend reducing or pausing
- Frame as: "shift toward," "pull back from," "increase the share of," "pause and reallocate"
- Never state dollar amounts

### Subsection 4: Discussion Points

3-5 collaborative alignment questions tied to specific audit findings.

Frame as partnership alignment, not interrogation:
- "We're planning to [specific action] -- want to confirm this aligns with your goals before we move forward."
- "We see an opportunity to test [specific format/audience/angle] -- is that something you'd want us to prioritize?"
- "Are there any upcoming [promos/launches/seasonal shifts] that would affect how we allocate budget over the next 2-4 weeks?"

Each point should reference a real finding from the audit.

### Subsection 5: Step-by-Step Action Items

Numbered list in implementation order (what to do first, second, third...).

Each item includes:
- A clear, specific action (e.g., "Pause UGC 2 in AI UGC 2 campaign")
- An owner (Media Buyer / Creative / Dev)
- A success metric or decision rule (e.g., "If ROAS stays below 3.50 after 7 days, proceed to next action")

5-8 items maximum. Order by urgency, then by dependency.

Total section should be readable aloud in under 2 minutes.

## Output format

1. **Creative Testing Roadmap** (video concepts, static concepts, copy variations, format experiments, seasonal angles)
2. **Full Creative Briefs** (1-3 only, for top opportunities)
3. **Prioritized Recommendations** (3-5 bullets)
4. **Discussion Points** (3-5 questions)
5. **Action Items** (5-8 numbered steps)
