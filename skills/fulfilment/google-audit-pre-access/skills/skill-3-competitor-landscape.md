# SKILL 3: Search & Competitor Landscape

## When to use

After Skill 2. Only run if the user provided competitor names or they were inferred in Skill 0. If competitors were skipped, proceed to Skill 4.

## What to do

### Step 1: Fetch competitor Transparency Center pages

For each competitor (1-2 max):

1. Navigate to Google Ads Transparency Center and search for the competitor
2. Take snapshots of their active ads
3. If their Transparency Center page is inaccessible, use web search to find competitor ad examples

### Step 2: Build competitor creative snapshots

For each competitor, produce:

**[Competitor Name]**

| Attribute | Finding |
|---|---|
| # of Active Ads | X |
| Format Mix | Search: X, Display: X, Video: X, Shopping: X |
| Primary Messaging Angles | [list top 2-3] |
| Sample Headlines | [2-3 strongest headlines] |
| Extension Usage | Sitelinks / Callouts / Structured Snippets / etc. |
| Landing Page Approach | [homepage vs dedicated LPs vs product pages] |

### Step 3: Comparison table

| Attribute | [Prospect] | [Competitor 1] | [Competitor 2] |
|---|---|---|---|
| Active Ad Volume | X | X | X |
| Format Diversity | X formats | X formats | X formats |
| Primary Angles | [list] | [list] | [list] |
| Extension Usage | [list] | [list] | [list] |
| Landing Page Strategy | [type] | [type] | [type] |
| Copy Specificity | High / Medium / Low | High / Medium / Low | High / Medium / Low |

### Step 4: Competitive gaps & opportunities

Based on the comparison, identify:

**Where the prospect is behind:**
- Angles, formats, or tactics competitors use that the prospect doesn't
- For each gap: why it matters and what the prospect should do about it

**Where the prospect is differentiated:**
- Strengths the prospect has that competitors don't
- How to lean into these advantages

**Untapped opportunities:**
- Angles or formats that neither the prospect nor competitors are using
- First-mover advantage potential

## Output format

1. **Competitor Creative Snapshots** (1 table per competitor)
2. **Comparison Table** (prospect vs competitors)
3. **Competitive Gaps & Opportunities** (behind, differentiated, untapped)

## Next step

Proceed automatically to Skill 4 (Opportunities & Next Steps).
