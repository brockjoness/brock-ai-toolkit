# FINAL OUTPUT ASSEMBLY -- Pre-Access Google Ads Audit

After all skills have run, compile the full report as a **client-facing sales document**. This is sent directly to the prospect -- it is not an internal working document. Apply all formatting and tone rules below before finalizing.

Do not output the final report incrementally during skill execution. Compile it at the end.

---

## SECTION ORDER

Present sections in this order:

1. **Executive Brief** (from Skill 4: Top 3 things working + Top 3 things to stop/fix + Key learnings)
2. **Ad Landscape Review** (from Skill 1: ad catalog summary, format diversity, messaging angle breakdown)
3. **Website & Landing Page Review** (from Skill 2: message match assessment, conversion optimization, quick wins)
4. **Competitor Snapshot** (from Skill 3: comparison table, gaps, opportunities)
5. **Opportunities & Next Steps** (from Skill 4: quick-win recommendations, "What a full audit would reveal")

---

## WHAT TO REMOVE ENTIRELY

Do not include any of the following in the final output:

- Raw ad catalog tables (summarize patterns, don't list every ad)
- Internal process notes, skill numbers, methodology descriptions
- "Data source type" labels
- Any language suggesting data was limited or unavailable
- Technical SEO details (keep it strategic, not technical)

---

## TONE AND FRAMING RULES

- Write as a **trusted advisor presenting a strategic assessment**, not as a system reporting data
- Use **"we" language** throughout -- this is a partnership pitch
- Be **confident and opinionated** -- make clear recommendations, don't hedge
- Frame gaps as **opportunities**, not problems
- Every finding includes **"why"** -- connect observations to search intent, conversion psychology, and competitive advantage
- No emojis, no code blocks, no HTML
- Keep it scannable -- use tables, bullets, bold headers
- Target length: **3-5 pages** when pasted into a doc

## OUTPUT FORMAT

Format as plain text with clear section headers and simple tables. Notion-compatible formatting: headers (#, ##, ###), bold for emphasis, bullet points for lists, pipe tables for data. No code blocks, no HTML.

Open with:

```
# [Brand Name] -- Google Ads Assessment
Report Date: [date]
Active Ads Observed: [count]
Ad Formats Detected: [list]
Competitors Reviewed: [names or "none"]
```
