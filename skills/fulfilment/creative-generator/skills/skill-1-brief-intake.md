# SKILL 1: Creative Brief Intake

## When to use

Immediately after Skill 0 (trigger). This skill parses the available input -- whether from a completed audit's creative deep dive or a manual brief -- into a structured set of 3 creative variant briefs.

## What to do

### Path A: From Audit Output (Creative Deep Dive)

Extract the following from the Skill 4 creative deep dive output:

**1. Top 3 Winning Patterns** (from "Creative Patterns That Work" table)
- For each pattern: the pattern type, why it works, visual/copy elements, replication guidance
- These become the basis for the 3 variants

**2. Best Headlines** (from "Copy & Messaging Mining")
- Pull the top-performing headline from each type:
  - Emotional / Aspirational
  - Functional / Benefit-Driven
  - Urgency / Promo
  - Identity-Based
- Assign the most relevant headline type to each variant based on the pattern it's testing

**3. Best Hooks** (from "Best Hooks" section)
- Extract the top hook lines -- these inform headline writing for story/reels format
- If video hooks exist, adapt the hook concept for static text overlay

**4. Winning CTAs** (from "CTA Analysis")
- Identify the top-performing CTA button text
- If no clear winner, default to "Shop Now" for e-commerce, "Learn More" for lead gen

**5. Static Design Patterns** (from "Static Creative Insights" if available)
- Visual composition patterns (layout, color usage, image style)
- Copy integration rules (headline placement, font contrast)

**Variant Assembly from Audit:**

| Variant | Source | Angle |
|---|---|---|
| Variant 1 | #1 winning pattern + best headline from matching type | Primary winning formula |
| Variant 2 | #2 winning pattern + headline from different type | Secondary angle |
| Variant 3 | Contrasting angle or anti-pattern fix | Test a gap or underused approach |

### Path B: From Manual Brief

Gather the following from the user (ask if not provided):

- **Product/service name** and one-line description
- **Target audience** (demographic, psychographic, or persona)
- **Key value propositions** (1-3 bullet points)
- **Headline options** (if provided) or key messaging themes
- **CTA text** (if provided) or default to "Shop Now" / "Learn More"
- **Image direction** (lifestyle, product-focused, UGC-style, before/after, etc.)
- **Tone** (aspirational, direct, playful, premium, etc.)

**Variant Assembly from Manual Brief:**

| Variant | Angle | Strategy |
|---|---|---|
| Variant 1 | Lead value prop | Strongest benefit, direct and clear |
| Variant 2 | Emotional / aspirational | How the product makes them feel or who they become |
| Variant 3 | Social proof or urgency | Testimonial-style or scarcity/FOMO angle |

## Output format

Produce a structured brief for each variant. This is the input for Skill 2.

```
VARIANT 1: [Variant Name]
- Angle: [Creative angle / pattern being tested]
- Headline: [Max 8 words]
- Body Copy: [1-2 lines, benefit-focused]
- CTA: [2-4 words]
- Image Direction: [Descriptive label for placeholder, or URL if provided]
- Strategic Rationale: [1 sentence -- why this variant, what it tests]

VARIANT 2: [Variant Name]
...

VARIANT 3: [Variant Name]
...

AGENCY: [agency slug or "neutral"]
CLIENT: [client name]
IMAGE URLS: [list of URLs if provided, or "none -- use placeholders"]
```

Proceed automatically to Skill 2.
