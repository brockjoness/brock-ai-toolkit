# SKILL 3: Competitor Snapshot

## When to use

After Skill 2 (Creative Analysis). Only run if competitor Ad Library URLs or names were provided in Skill 0.

If no competitors were identified, skip to Skill 4 (Website Review).

## What to do

### Step 1: Fetch competitor Ad Libraries

For each competitor (1-2 max):

1. Navigate to their Meta Ads Library URL using Chrome DevTools MCP
2. Take snapshots to capture all active ads
3. If no direct URL, search the Ad Library by brand name

### Step 2: Quick-scan competitor creative

For each competitor, produce a brief summary (not a full audit):

**[Competitor Name] -- Creative Snapshot**

| Metric | Value |
|---|---|
| Total Active Ads | X |
| Format Mix | X video / X static / X carousel |
| Primary Messaging Angle | [angle] |
| Estimated Ad Volume Trend | [growing / stable / declining based on start dates] |

**Notable Tactics:**
- 3-5 bullet points on what the competitor is doing that stands out
- Focus on: unique angles, strong hooks, format choices, copy patterns, landing page strategy

### Step 3: Comparative analysis

Produce a comparison table:

| Dimension | Prospect | Competitor 1 | Competitor 2 |
|---|---|---|---|
| Total Active Ads | X | X | X |
| Video % | X% | X% | X% |
| Dominant Angle | [angle] | [angle] | [angle] |
| UGC Present? | Yes/No | Yes/No | Yes/No |
| Carousel Present? | Yes/No | Yes/No | Yes/No |
| Unique Differentiator | [what they do differently] | [what they do differently] | [what they do differently] |

### Step 4: Competitive gaps & opportunities

Based on the comparison, identify:

1. **Where the prospect is behind**: Angles, formats, or tactics competitors are using that the prospect is not
2. **Where the prospect is differentiated**: Things the prospect does that competitors don't -- these are strengths to double down on
3. **Competitive blind spots**: Things neither the prospect nor competitors are doing -- first-mover opportunity

Frame these as opportunities, not criticism. This is a sales document.

## Output format

1. **Competitor Creative Snapshots** (one per competitor)
2. **Comparison Table**
3. **Competitive Gaps & Opportunities** (3-5 bullets)

## Next step

Proceed automatically to Skill 4 (Website Review).
