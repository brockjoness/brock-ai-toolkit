# SKILL 4: Website & Landing Page Review

## When to use

After Skill 3 (Competitor Snapshot) or Skill 2 (if competitors were skipped). Only run if a website URL is available.

If no website URL is available, skip to Skill 5 (Opportunities).

## What to do

### Step 1: Review landing pages from ads

Using the landing page URL list from Skill 1, visit the top 3-5 most-used landing pages:

1. Navigate to each URL using Chrome DevTools MCP or WebFetch
2. Capture the page content (above-the-fold and below-the-fold)

If pages cannot be fully analyzed (authentication, CAPTCHAs, JavaScript-heavy), note the limitation and assess what is observable.

### Step 2: Message match assessment

For each landing page, evaluate the ad-to-page continuity:

**[Landing Page URL]**

| Dimension | Assessment |
|---|---|
| Message match | Does the ad promise match what the page delivers? |
| Visual continuity | Does the brand aesthetic carry through from ad to page? |
| Offer clarity | Is the offer/value prop clear within 5 seconds? |
| Trust signals | Reviews, guarantees, social proof visible above the fold? |
| CTA clarity | Is the next action obvious? |

Classify each as **Strong Match** or **Weak Match / Friction Flag**.

For weak matches, explain the specific mismatch:
- "Ad promises [X], but page delivers [Y]"
- "Ad targets [persona], but page has no [persona]-specific messaging"

### Step 3: Quick-win callouts

Identify 3-5 specific, actionable landing page improvements the prospect could make immediately:

- Frame as opportunities, not criticism (this is a sales document)
- Be specific: "Add [X] above the fold on [page]" not "Improve your landing pages"
- Examples: dedicated collection pages for specific creative angles, trust signals, gift-wrapping options, size guides, persona-specific messaging

### Step 4: Trust signal audit

Check for these across the main landing pages:

- Star rating + review count visible above the fold?
- Fabric/material/quality callout?
- Size/fit reassurance (size guide, "true to size" badge)?
- Return policy visible?
- Social proof ("loved by X+ customers", "as seen in...")?
- Founder/brand story accessible?

Note what's present and what's missing.

## Output format

1. **Landing Page Message Match Table** (one row per page, strong/weak classification)
2. **Weak Match Details** (specific mismatches with fixes)
3. **Quick-Win Callouts** (3-5 actionable improvements)
4. **Trust Signal Audit** (present vs. missing checklist)

Proceed automatically to Skill 5 (Opportunities & Next Steps).
