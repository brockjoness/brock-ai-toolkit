# SKILL 8: Action Plan

## When to use

After all prior skills have run. This is always the final analysis skill.

## What to do

### Subsection 1: Testing Roadmap

Based on all findings from Skills 3-7, propose specific tests and changes. This covers more ground with less detail than full briefs.

**Ad Copy Tests** (3-5):
For each:
- Campaign / ad group target
- Current approach vs proposed test (specific headlines/descriptions)
- Why test (cite data justification -- which pattern, gap, or opportunity does this address?)
- Priority (1/2/3)

**Keyword Expansion Opportunities** (3-5):
For each:
- Recommended keyword or keyword theme
- Match type
- Justification (from search term analysis, competitor gaps, or missing coverage)
- Estimated impact
- Priority (1/2/3)

**Bidding Strategy Changes** (1-3):
For each:
- Campaign affected
- Current strategy -> recommended strategy
- Why change (cite performance data)
- Implementation notes (transition period, monitoring cadence)

**Shopping/PMax Optimizations** (2-3, if applicable):
For each:
- Optimization type (feed improvement, asset group restructure, audience signal update, listing group change)
- Specific change
- Expected impact

**Landing Page Tests** (1-3, if applicable):
For each:
- Page URL
- Current issue
- Proposed test (A/B test or direct change)
- Expected impact on conversion rate / QS

**Negative Keyword Additions** (if search term analysis was run):
- List of recommended negative keywords grouped by theme
- Match type for each (exact or phrase)
- Estimated spend savings

### Subsection 2: Full Briefs (Top 1-3 Opportunities Only)

Generate full briefs ONLY for the highest-priority opportunities. The testing roadmap handles the rest.

For each brief:

**BRIEF #[N] -- [Opportunity Title]**

1. **Strategic Opportunity:** One paragraph. What did the data reveal? Reference specific metrics and compare to baseline. Why does this brief exist?

2. **Target Audience:** Who is this for? Demographics, search intent, funnel stage.

3. **Ad Copy Framework:**
   - Primary message (recommended)
   - Alternative angle 1
   - Alternative angle 2
   - 3-5 specific headline options (actual copy)
   - 2-3 description options (actual copy)

4. **Keyword / Targeting Specs:**
   - Recommended keywords and match types
   - Negative keywords to include
   - Audience signals (for PMax/Display/YouTube)

5. **Landing Page Requirements:**
   - Recommended landing page
   - Required elements above the fold
   - Message match checklist

6. **KPI Targets:**

   | Metric | Account Baseline | Target |
   |---|---|---|
   | CTR | X% | X% |
   | CPC | $X | $X |
   | CPA | $X | $X |
   | ROAS | X.XX | X.XX |

7. **Test Parameters:**
   - Campaign / ad group to deploy in
   - Test against: [control]
   - Minimum spend before decision: [$X]
   - Decision metric and threshold
   - If winner / if loser: next action

### Subsection 3: Prioritized Recommendations

3-5 bullets, high priority first.

Format: "We recommend [X] because [data showed Y]"

Include directional budget guidance:
- If a campaign type or campaign has significantly better ROAS, recommend increasing its share
- If a campaign is burning spend with poor returns, recommend reducing or pausing
- Frame as: "shift toward," "pull back from," "increase the share of," "pause and reallocate"
- Never state dollar amounts

### Subsection 4: Discussion Points

3-5 collaborative alignment questions tied to specific audit findings.

Frame as partnership alignment, not interrogation:
- "We're planning to [specific action] -- want to confirm this aligns with your goals before we move forward."
- "We see an opportunity to test [specific keyword/audience/channel] -- is that something you'd want us to prioritize?"
- "Are there any upcoming [promos/launches/seasonal shifts] that would affect how we allocate budget over the next 2-4 weeks?"
- "We noticed [structural observation] -- is there a reason the account is set up this way, or can we restructure?"

Each point should reference a real finding from the audit.

### Subsection 5: Step-by-Step Action Items

Numbered list in implementation order (what to do first, second, third...).

Each item includes:
- A clear, specific action (e.g., "Add 47 negative keywords to Non-Brand Search campaigns")
- An owner (Media Buyer / Dev / Client)
- A success metric or decision rule (e.g., "If CPA drops by 10% within 14 days, expand to remaining campaigns")

5-8 items maximum. Order by urgency, then by dependency.

Total section should be readable aloud in under 2 minutes.

## Output format

1. **Testing Roadmap** (ad copy, keywords, bidding, Shopping/PMax, landing pages, negatives)
2. **Full Briefs** (1-3 only, for top opportunities)
3. **Prioritized Recommendations** (3-5 bullets)
4. **Discussion Points** (3-5 questions)
5. **Action Items** (5-8 numbered steps)
