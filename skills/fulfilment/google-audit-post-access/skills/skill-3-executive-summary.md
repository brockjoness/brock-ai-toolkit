# SKILL 3: Executive Summary

## When to use

After Skill 2 has computed baselines.

## What to do

### Subsection 1: Account Snapshot Table

| Metric | Value |
|---|---|
| Total Spend | $X |
| Total Impressions | X |
| Total Clicks | X |
| Average CPC | $X.XX |
| Average CTR | X.XX% |
| Total Conversions | X |
| Average CPA | $X.XX |
| Total Revenue | $X (if available) |
| Weighted ROAS | X.XXx (if available) |
| Search Impression Share | X% (if available) |
| Campaign Types Active | Search, Shopping, PMax, etc. |
| Date Range | [start] to [end] |
| Attribution Model | [model] |

### Subsection 2: Top 3 Winners

Identify the three best-performing campaigns, ad groups, keywords, or ads by ROAS (or CPA if revenue is absent).

For each winner:

**[Winner Name]**
- **Performance:** [key metrics vs baseline]
- **Why it works:** 3-5 sentences explaining the strategic and tactical reasons this outperforms. Connect ad copy, keyword targeting, landing page alignment, and audience signals to the result. Explain the conversion psychology -- what makes this resonate with the search intent? Reference specific elements (headline structure, keyword-to-ad relevance, bidding strategy alignment).

### Subsection 3: Top 3 Patterns to Replicate

Identify three recurring patterns across top performers. These are not individual winners but themes (e.g., "benefit-led headlines consistently outperform feature-led," "exact match keywords drive 40% lower CPA than broad match," "PMax campaigns targeting specific audience signals outperform generic setups").

For each pattern:
- **Pattern:** One-sentence description
- **Evidence:** Which campaigns/ad groups demonstrate this pattern, with metrics
- **How to replicate:** Tactical instructions -- what to build, how to structure it, where to deploy it

### Subsection 4: Top 3 Things to Stop

Identify three practices, campaigns, or patterns that are actively hurting performance.

For each:
- **What to stop:** One-sentence description
- **Why it fails:** Data-backed explanation with specific metrics vs baseline
- **What to do instead:** A concrete alternative (not just "improve" -- specify the change)

### Subsection 5: Key Learnings Summary

3-5 bullets summarizing the most important takeaways across the account:
- What the account does well overall
- Where the biggest efficiency gaps are
- Seasonal or timing context if relevant
- Channel mix observations (Search vs Shopping vs PMax allocation)
- Bidding strategy observations
- Any structural issues (campaign architecture, match type coverage, negative keyword hygiene)

## Output format

1. **Account Snapshot** (table)
2. **Top 3 Creative/Campaign Winners** (with "why it works")
3. **Top 3 Patterns to Replicate** (with tactical instructions)
4. **Top 3 Things to Stop** (with concrete alternatives)
5. **Key Learnings Summary** (3-5 bullets)

This section should be powerful enough to stand alone as a summary for executives who won't read the full report.
