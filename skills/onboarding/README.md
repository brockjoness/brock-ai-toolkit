# Onboarding Skills

The "after the deal closes, before the first report" stretch. These skills cover everything from parsing a new intake form through generating contracts, sending the first invoice, drafting the welcome email, and producing the branded pre-kickoff deliverable suite (competitor research, audits, roadmap) that makes a client feel like work is already in motion.

## Skills

| Skill | What it does | Maturity |
|---|---|---|
| [client-onboarding](./client-onboarding/) | Full CRM-driven launch handoff: contract, invoice, welcome email, Notion task, status update | production |
| [competitor-research](./competitor-research/) | Generates a structured competitor research deliverable per client | working |
| [onboarding-intake-processor](./onboarding-intake-processor/) | Parses a new client intake form into a CRM row + kickoff prep doc | working |
| [pre-onboarding](./pre-onboarding/) | Produces a hub of branded pre-kickoff deliverables (competitor research, Meta + Google audits, 12-month roadmap) | production |
| [strategy-pipeline](./strategy-pipeline/) | Multi-layer strategy workflow: positioning, audience, offer, creative, channels, measurement | working |

See each skill's `README.md` for setup, env vars, and limitations.
