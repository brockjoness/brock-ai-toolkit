# Competitor Research — Output Template

## Client-Facing Format

When the competitor research output is used as a standalone client deliverable (not just internal input for other skills), format as a **Competitive Intelligence Brief** with these sections:

1. **Executive Summary** (3-4 sentences) — What we found, what it means, what to do about it
2. **Market Sentiment** — Reddit + X + Reviews consolidated into a single narrative
3. **Competitive Landscape** — Competitor positioning table with activity signals
4. **Customer Voice** — Top pain points and objections in customer's own language
5. **Strategic Opportunities** — Messaging angles, positioning gaps, creative themes
6. **Recommended Actions** — Prioritized next steps

## Internal Format (Skill Chain Input)

When used as input for downstream skills (creative-brief-generator, pre-onboarding roadmap), the full 7-section format from skill-1-competitor-research.md is used. The key handoff is **Section 7: Creative Brief Input Summary** — this structured block feeds directly into the creative brief generator.

## Formatting Rules

- Tables for data, bullets for insights, blockquotes for user language
- Every insight must cite its source (Reddit, reviews, X, competitive analysis)
- Frequency/volume signals where possible (High/Medium/Low)
- No hedging — commit to directional recommendations
- Flag thin data explicitly: "Limited data — only X mentions found"
