# Retention Skills

The two highest-leverage retention moments for an agency: catching churn risk early, and nailing the QBR. These skills make both repeatable instead of one-off heroic efforts.

## Skills

| Skill | What it does | Maturity |
|---|---|---|
| [churn-risk-detector](./churn-risk-detector/) | Scans client portfolio for early churn signals, ranks accounts, recommends save plays | working |
| [qbr-generator](./qbr-generator/) | Full Quarterly Business Review from 90 days of data + context: wins, challenges, deep dives, next-quarter strategy | production |

See each skill's `README.md` for setup, env vars, and limitations.
