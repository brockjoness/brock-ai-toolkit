# Operations SOPs

Standard operating procedures for the operations side of an agency workspace. These are documentation, not Claude skills — they describe pipelines and timing targets that the named skills implement.

| SOP | One-liner |
|---|---|
| [`onboarding-pipeline.md`](./onboarding-pipeline.md) | Intake form → CRM update → audit/pre-onboarding deploy → kickoff call → launch, with a 24-hour intake-to-kickoff target and 48-hour kickoff-to-launch target. |

See `_FLAGS.md` in this folder for sanitization notes.
